## Scope and scoring rules

I consulted only the five supplied inputs: `article.pdf`, `source.yaml`, `01_claims_reference.md`, `02_baseline_answers.md`, and `04_close_reading_answers.md`. I did not open the close-reading JSON mentioned inside Method B or consult outside sources. The reference’s Evidence paragraphs inform interpretation but do not create additional R entries.

The three relevance lists below are exactly those supplied. Recall is the number of distinct relevant R entries used within each numbered answer, divided by that question’s fixed denominator. A substantive assertion from an entry can be used through an exact excerpt or an explicit, faithful paraphrase; the answer need not reproduce every sentence, qualification, or example in a compound entry. This is use, not exhaustive reproduction. The reference contains overlapping and cumulative entries, which remain separate R numbers because the supplied denominator fixes them. Each entry counts once per answer, even when several quotations use it. For every R number in a missed list, the reason is that I found no explicit substantive assertion or faithful paraphrase of that entry within that numbered answer under this rule; a related theme or information supplied only by the reference does not fill that gap. Used compound entries may still have unaddressed content, identified in the coverage notes. I do not credit a merely related theme, the reference’s unquoted supporting evidence, or the shared introductory description automatically to all three answers.

Precision uses each outer quotation block as one quotation, even when it contains several sentences or nested quotation marks. Repeated quotations in different answers count separately. Each must be exact, match a real reference claim, bear on its assigned question, and preserve the reference’s speaker/view attribution. A faithful excerpt can match a longer reference claim. A quotation containing multiple reference claims passes relevance when its use for the question is supported by the fixed relevant entries mapped below.

I extracted all 28 PDF pages with Apple PDFKit, invoked through Swift. I checked quotation strings against the extracted article text, normalizing typography, whitespace, page headers, and discretionary line-break hyphenation. I also rendered and inspected printed pp. 113, 114, 115, and 119 as images: the first three for the baseline’s figure description and p. 119 for the compound “letter-sounds” across a line break. These layout normalizations do not license substitutions or paraphrases as exact quotations. Baseline A1.09 retains the PDF’s footnote marker in `online7`; this is the superscript note 7, not an added word or an inexact quotation.

The unquoted, explicitly labeled figure description in Method A’s third answer is answer item A3.12. It contributes to recall but is not a quotation and is excluded from precision. Thus A3 has 18 answer items but 17 quotations. Citation text, headings, and close-reading identifiers are not extra quotation units.

## Comparison and null hypothesis

Method A uses 103/623 relevant question–claim pairs (16.53%); Method B uses 109/623 (17.50%). B’s change in used claims is Q1: -4, Q2: +9, Q3: +1, for +6 overall (+0.96 percentage points). Method B therefore beats Method A on pooled recall, although not on every question. Precision is tied at 100%: A passes 54/54 quotations and B passes 72/72. For this article, the null that B is no better does not stand for pooled recall, but it stands for precision: the improvement is coverage, not quotation accuracy. This is a descriptive result for one article, not a statistical significance test. The overlap and compound structure of the fixed reference entries make the per-entry mappings and coverage notes important to interpreting recall.
