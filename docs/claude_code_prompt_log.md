# Claude Code Prompt Log

This log records the prompts and responses exchanged with Claude Code while
developing this project. It exists so the reasoning and decisions behind the
project's structure — not just the resulting code and documentation — remain
visible to future contributors and sessions.

Entries are organized by build-plan phase, one file per phase, numbered
locally within that phase.
